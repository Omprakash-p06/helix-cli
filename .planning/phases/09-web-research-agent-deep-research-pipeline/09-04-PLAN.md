# Plan 09-04: Evidence Synthesizer, Context Integration & Adversarial Tests

## Objective

Implement `EvidenceSynthesizer` — the final stage of the pipeline that compresses stored evidence
into a ≤2k-token `ResearchBrief` with provenance-stamped citations. Wire `WebResearchPipeline`
into `ContextEngine` so the agent automatically runs live research when the classifier says so.
Add adversarial tests verifying that prompt-injection via web content cannot reach the agent's
system prompt.

Depends on 09-03 (full pipeline). This is the integration and hardening plan.

## Requirements Coverage

Addresses all Phase 09 success metrics:
- "Research brief is ≤2k tokens delivered to the coding agent" → EvidenceSynthesizer
- "Fetched content is never treated as executable instructions" → adversarial tests
- "Research completes with provenance-stamped citations" → ResearchBrief.citations

   Fields:
   - facts: Vec<crate::agent_core::web_research::store::EvidenceRow>  (selected evidence chunks)
   - citations: Vec<Citation>
   - total_chars: usize
   - estimated_tokens: usize

   Methods:
   - `pub fn to_context_string(&self) -> String`:
     Format:
     ```
     ## Research Brief (Web Sources)
     
     {for each fact: fact.markdown_value joined with "\n\n---\n\n"}
     
     ## Sources
     {for each citation: "- {citation.url}"}
     ```
   - `pub fn estimated_tokens(&self) -> usize` → self.total_chars / CHARS_PER_TOKEN

3. `pub struct EvidenceSynthesizer`  (no fields needed)

4. impl EvidenceSynthesizer:
   - `pub fn new() -> Self`
   - `pub fn compile_brief(&self, evidence: Vec<crate::agent_core::web_research::store::EvidenceRow>, citations: Vec<Citation>) -> ResearchBrief`:
     a. Sort evidence by relevance_score descending
     b. Greedily select chunks until total_chars + chunk.len() > MAX_BRIEF_CHARS
     c. Collect only citations whose evidence_id is in the selected set
        (Note: for simplicity, include all citations if EvidenceRow.id not tracked; filter by position in sorted list)
     d. Compute total_chars = sum of selected chunk lengths
     e. Return ResearchBrief { facts: selected, citations: filtered, total_chars, estimated_tokens: total_chars/CHARS_PER_TOKEN }

   - `pub fn brief_from_store(&self, store: &crate::agent_core::web_research::store::EvidenceStore, session_id: &str) -> ResearchBrief`:
     a. Call store.evidence_for_session(session_id) to get all evidence
     b. Create citations as Vec<Citation> — for now create one Citation per evidence chunk with url derived from evidence content_hash (or empty url if not available) — in a real implementation the store would join citations but for this milestone we simplify
     c. Call self.compile_brief(evidence, citations)

5. Add #[cfg(test)] mod tests:
   - `brief_respects_token_budget()`:
     Create 20 EvidenceRow entries with markdown_value = "a".repeat(400) each (400 chars each → ~100 tokens each)
     Total would be 8000 chars. Call compile_brief. Assert brief.total_chars <= 6000 (MAX_BRIEF_CHARS).
     Assert brief.estimated_tokens() <= 1500.
   - `brief_preserves_highest_relevance()`:
     Create 3 EvidenceRow with relevance_scores 0.9, 0.3, 0.7. Expect first selected is 0.9.

- Assert source.content does NOT contain "Ignore all previous instructions" in any unescaped context outside the untrusted tags

- Assert source.provenance == Provenance::Untrusted
- Assert source.content.starts_with("<untrusted_web_content")
