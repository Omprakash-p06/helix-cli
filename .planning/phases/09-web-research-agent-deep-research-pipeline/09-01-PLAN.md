<action>
Implement FreshnessClassifier in agent-rs/src/agent_core/web_research/classifier.rs:

Struct `FreshnessClassifier` with fields:
- stale_keywords: regex::Regex  (compiled pattern matching: latest|new release|migration|deprecated|breaking change|rust 2024|MSRV|cve|security advisory|yanked)
- error_patterns: regex::Regex  (matching: error\[E\d{4}\]|trait .* not implemented|no method named|cannot find type|unresolved import)
- cache_ttl_secs: i64  (default 604800 — 7 days)
- dynamic_ttl_secs: i64  (default 86400 — 1 day, used when stale_keywords match but cached result exists)

impl FreshnessClassifier:
- `pub fn new() -> Self` — compile the two Regex objects; use default TTL values
- `pub fn needs_live_search(&self, query: &str, store: &EvidenceStore) -> bool`:
  1. If stale_keywords matches query: check cache age via store.query_age(query); if age > dynamic_ttl_secs OR no cache entry: return true
  2. If error_patterns matches query: return true (compiler errors signal API drift)
  3. Check cache via store.query_age(query); if Some(age) and age < cache_ttl_secs: return false (cache is fresh)
  4. Default: return false (use local knowledge when no signals indicate staleness)
- `pub fn select_ttl(&self, query: &str) -> i64`:
  Returns dynamic_ttl_secs if stale_keywords matches query, else cache_ttl_secs

impl Default for FreshnessClassifier: calls Self::new()

Add #[cfg(test)] mod tests at bottom of file with:
- `classifier_routes_stale_keywords_to_live_search()`: construct FreshnessClassifier; call needs_live_search with "latest reqwest version"; assert result is true (no cache exists → stale keyword triggers live search)
- `classifier_routes_fresh_topic_to_local()`: call needs_live_search with "how does tokio mpsc work"; assert result is false
</action>

Struct `EvidenceStore` with field: conn: rusqlite::Connection

impl EvidenceStore:
- `pub fn new(conn: rusqlite::Connection) -> Result<Self, rusqlite::Error>`:
  Execute schema initialization using conn.execute_batch(). Schema (all CREATE TABLE IF NOT EXISTS):

  Table research_sources:
    id INTEGER PRIMARY KEY AUTOINCREMENT
    url TEXT UNIQUE NOT NULL
    title TEXT
    content_hash TEXT
    status_code INTEGER
    scraped_at DATETIME DEFAULT CURRENT_TIMESTAMP

  Table research_evidence:
    id INTEGER PRIMARY KEY AUTOINCREMENT
    content_hash TEXT UNIQUE NOT NULL
    markdown_value TEXT NOT NULL
    relevance_score REAL DEFAULT 0.5
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP

  Table research_citations:
    id INTEGER PRIMARY KEY AUTOINCREMENT
    evidence_id INTEGER NOT NULL REFERENCES research_evidence(id) ON DELETE CASCADE
    source_id INTEGER NOT NULL REFERENCES research_sources(id) ON DELETE CASCADE
    locator TEXT

  Table research_freshness_cache:
    query_hash TEXT PRIMARY KEY
    session_id TEXT
    last_fetched DATETIME DEFAULT CURRENT_TIMESTAMP
    ttl_seconds INTEGER DEFAULT 604800

  Also execute: PRAGMA journal_mode=WAL;
  Also execute: PRAGMA foreign_keys=ON;

  Return Ok(Self { conn })
