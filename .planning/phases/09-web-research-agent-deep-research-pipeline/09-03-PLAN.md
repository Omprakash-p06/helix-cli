# Plan 09-03: Research Pipeline Orchestrator — Planner, Worker Pool & Fetch Loop

## Objective

Implement the live-fetch pipeline: `ResearchPlanner` decomposes a natural-language query into
concrete HTTP fetch tasks; `WorkerPool` runs N=4 concurrent async workers with rate-limiting,
SSRF checks, 30s timeouts, 1MB size limits, HTML sanitization, and EvidenceStore writes.
Exposes a `WebResearchPipeline::run()` entry point that orchestrates the full flow.

Depends on 09-01 (EvidenceStore, schema) and 09-02 (sanitize_html_to_markdown, is_ssrf_safe).

## Requirements Coverage

Addresses Phase 09 success metric: "Research completes with provenance-stamped citations."

<action>
Implement WorkerPool in agent-rs/src/agent_core/web_research/worker.rs:

1. Use these imports: tokio::sync::mpsc, tokio::time::{timeout, Duration},
   std::sync::{Arc, Mutex}, governor::{Quota, RateLimiter, state::direct::NotKeyed, state::InMemoryState, clock::DefaultClock},
   nonzero_ext::nonzero, sha2::{Sha256, Digest}, hex

2. Type alias: `type SharedRateLimiter = Arc<RateLimiter<NotKeyed, InMemoryState, DefaultClock>>`

3. `pub struct WorkerPool { num_workers: usize, request_timeout_secs: u64, max_body_bytes: usize }`

4. impl WorkerPool:
   - `pub fn new(num_workers: usize) -> Self`:
     Set request_timeout_secs = 30, max_body_bytes = 1_048_576 (1MB)
   - `pub async fn run(&self, tasks: Vec<crate::agent_core::web_research::planner::SearchTask>, store: Arc<Mutex<crate::agent_core::web_research::store::EvidenceStore>>) -> Result<usize, Box<dyn std::error::Error>>`:
     Returns the count of successfully processed tasks.

     Implementation:
     a. Create a governor rate limiter: Quota::per_second(nonzero!(2u32)) → RateLimiter::direct(quota) → wrap in Arc
     b. Create tokio::sync::mpsc::channel::<SearchTask>(32). Send all tasks into tx, then drop tx.
     c. Wrap rx in Arc<Mutex<_>>
     d. Spawn self.num_workers tokio tasks. Each worker:
        - Loop: lock rx, call recv(), drop lock immediately
        - On None: break (channel closed)
        - On Some(task): rate_limiter.until_ready().await
          If !is_ssrf_safe(&task.url): log warn "SSRF blocked: {url}", continue
          Let fetch_result = timeout(Duration::from_secs(self.request_timeout_secs), reqwest_fetch(&task.url, self.max_body_bytes)).await
          Match fetch_result:
            Ok(Ok((html, status_code))) → sanitize, store result (see below)
            Ok(Err(e)) → log tracing::warn!("fetch error for {}: {}", task.url, e); continue
            Err(_) → log tracing::warn!("fetch timeout: {}", task.url); continue
     e. After spawning, wait for all JoinHandles with join_all or join! — collect success count
     f. Return Ok(success_count)

5. Private async fn reqwest_fetch(url: &str, max_bytes: usize) -> Result<(String, u16), Box<dyn std::error::Error>>:
   - reqwest::Client::builder().build()?
   - .get(url).send().await?
   - Check content_length; if > max_bytes: return Err("body too large")
   - let status = response.status().as_u16()
   - let bytes = response.bytes().await? (check len <= max_bytes)
   - let html = String::from_utf8_lossy(&bytes).into_owned()
   - Ok((html, status))

6. After sanitize_html_to_markdown(html, url) returns a ContentSource:
   - Compute content_hash = hex::encode(Sha256::digest(content_source.content.as_bytes()))
   - Lock store, call: store.insert_source(url, None, &content_hash, status_code)?
   - store.insert_evidence(&content_hash, &content_source.content, 0.5)?
   - Unlock store, log success
</action>
