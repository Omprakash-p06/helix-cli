# Helix CLI

A local-first AI assistant that runs entirely on your machine — no cloud APIs, no data leaving your computer.

## What it is

Helix CLI connects a local LLM (like Llama.cpp or KoboldCPP) with tools that let the AI read and write files, search your codebase, browse the web, and execute commands — all through a terminal or TUI interface.

## Quick start

```bash
python start.py
```

This runs setup (if needed), launches the model server, and drops you into the agent CLI.

## Commands

| Command | Description |
|---------|-------------|
| `python start.py` | Full stack launcher |
| `python scripts/start_server.py` | Start model server only |
| `cd agent-rs && cargo run` | Start agent CLI only |
| `python setup.py` | First-time setup |

## Modes

- **Terminal** (default) — classic REPL with readline
- **TUI** — `HELIX_UI_MODE=tui` for rich streaming UI
- **Web** — `HELIX_UI_MODE=web` for HTTP API

## Configuration

Set via environment variables or `scripts/config.py` (generated by setup):

| Variable | Default | Description |
|----------|---------|-------------|
| `HELIX_UI_MODE` | `terminal` | `terminal`, `tui`, or `web` |
| `AGENT_PERSONA` | `os_assistant` | `coder`, `researcher`, or `os_assistant` |
| `GPU_LAYERS` | auto | GPU offload layers |
| `HELIX_CONTEXT_SIZE` | auto | Context window size |

## Requirements

- Python 3.10+
- Rust toolchain (`rustup`)
- A GGUF model in `models/`

## Project layout

```
start.py              — One-command launcher
setup.py              — Hardware detection + setup
scripts/              — Python helpers (server, branding, model install)
agent-rs/             — Rust agent (orchestrator, tools, TUI, context engine)
web-ui/               — React web interface (optional)
models/               — Downloaded models
logs/                 — Runtime logs
```
